# Editeur_images

 [Rapport_JavaFX.pdf](https://github.com/user-attachments/files/34078563/Rapport_JavaFX.pdf)
 
Rapport du projet — Présentation de la conception et du développement d’une application Java de gestion et de traitement d’images. Le rapport détaille notamment l’architecture MVC, l’interface JavaFX, les filtres d’image, la gestion des tags, la sauvegarde JSON avec Jackson ainsi que le chiffrement et le déchiffrement des images.
